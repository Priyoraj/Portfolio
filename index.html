Projects

My Recent Works

PaperBot: Automated Research-Paper Request Assistant

Python, Tkinter, Playwright, SQLite, IMAP/SMTP

  • Desktop app that answers colleagues' paper requests by e-mail: finds each paper (Crossref, arXiv, Semantic Scholar), sends open-access copies first, and uses institutional VPN access only within daily fair-use limits.
  • Handles approval of new requesters, a queue for papers that need a manual download, and several computers sharing one mailbox; covered by 150+ automated tests.
Live demo Source code

FoCT Virtual Labs: Browser-based Computer Labs

Python, JavaScript, WebAssembly

  • Built for the Faculty of Computer Technology, Assam down town University: labs for C, C++, Python/Jupyter, Java, SQL, MongoDB, compiler design, circuit and network simulation, and packet analysis.
  • Compilers and runtimes run as WebAssembly in each student's browser, so one ordinary PC serves a whole lab offline.
  • Exam mode with copy/paste lock, watermarking, collection of students' work and a code-similarity report; load-tested with 500 simultaneous clients.
Live demo Source code

crypto-web: Encryption & Decryption Web Application

JavaScript, HTML, CSS

  • Teaching tool for the Caesar, Playfair and DES / Triple-DES ciphers that shows the Playfair key square and every round of DES; runs in any browser without installation.
Live demo Source code
